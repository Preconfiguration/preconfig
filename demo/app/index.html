          What is real here
          
      
          
        
          
          
          Real
          
          
            
            
          • Every line in the terminal in steps 1, 2, 3 and 6: what the command-line engine printed on the sample repositories, recorded on  and replayed at a readable pace.
            • 
            
          • Steps 4 and 5: two runs of preconfig verify on a clean Ubuntu 24.04 container on , from verify's own JSON events and the machine's own output, replayed five times faster. The minutes and seconds are the recorded ones.
            • 
            
          • The files, the findings and the drafts in the two panels above, and the build in step 2: the Alpha's own Go code, compiled to WebAssembly for this page. A test compares its answers with the same code built with standard Go, and the files it writes with the command line's, byte for byte.
            • 
          
          
        
          
        
          
          
          Stand-ins
          
          
            
            
          • orders-api is a small sample service written for this demo, and the hand-written files of step 3 were written to show common mistakes.
            • 
            
          • No coding agent runs here. The files are checked against each platform's published format and schema, and the setup script was run on a clean machine; Copilot, Cursor and Codespaces themselves did not run them for this demo.
            • 
            
          • The test machine reaches the internet through a proxy that inspects TLS, so verify ran with --network host and the proxy's certificate, shown here as proxy-ca.crt.
